## 📖 Overview

**Partially** provides an intuitive, distraction-free interface to partially mask, redact, or transform text segments in real time. Built with privacy and performance at its core, all processing runs 100% locally in your browser—ensuring sensitive strings, tokens, and data never leave your device.

---

## ✨ Features

- 🔒 **100% Private & Client-Side:** No servers, no tracking, and no external API calls. Everything executes entirely in-memory within your browser.
- ⚡ **Instant Processing:** Real-time character masking and text manipulation as you type.
- 🎛️ **Granular Controls:** Effortlessly configure indices, visibility ranges, delimiters, and masking characters.
- 📋 **One-Click Clipboard:** Rapid copy-to-clipboard functionality to keep your workflow seamless.
- 📱 **Clean & Responsive UI:** Modern, distraction-free design tailored for mobile, tablet, and desktop screens.
